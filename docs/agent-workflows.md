# Agent Workflow 与 Tool Calling 设计

## 1. 设计目标

本项目的数字人不应只依赖一次模型生成，而应通过 Agent Workflow 将多个工具组合成稳定、可控、可追踪的服务流程。

基本原则：

- 模型负责理解、判断、生成和协调。
- 工具负责检索、计算、规划、推荐和写入。
- Workflow 负责定义服务流程、失败兜底和结果校验。

## 2. 核心工具清单

### 2.1 文化知识检索

工具名：`search_cultural_knowledge`

用途：

- 检索景点、展品、人物、历史事件、文化故事。
- 为讲解生成提供依据。
- 降低模型幻觉。

输入：

- `query`
- `spot_id`
- `topic`
- `user_level`
- `language`

输出：

- 相关知识片段。
- 来源。
- 可信度。
- 推荐讲解角度。

### 2.2 景点推荐

工具名：`recommend_spots`

用途：

- 根据当前位置、用户偏好、剩余时间推荐下一站。

输入：

- `current_location`
- `visited_spots`
- `interest_profile`
- `available_time`
- `crowd_level`

输出：

- 推荐点位列表。
- 推荐理由。
- 预计耗时。
- 与用户兴趣的匹配原因。

### 2.3 路线规划

工具名：`plan_route`

用途：

- 生成可执行参观路线。

输入：

- `start_location`
- `target_spots`
- `available_time`
- `pace`
- `constraints`

输出：

- 路线节点。
- 每站预计时间。
- 总耗时。
- 替代路线。

### 2.4 个性化讲解生成

工具名：`generate_explanation`

用途：

- 结合知识库、用户画像和当前场景生成讲解。

输入：

- `knowledge_snippets`
- `user_profile`
- `context`
- `style`
- `length`

输出：

- 讲解文本。
- 语音播报文本。
- 可选追问。
- 推荐下一步动作。

### 2.5 互动任务触发

工具名：`trigger_task`

用途：

- 根据场景和用户状态触发探索任务、答题、打卡、收集类玩法。

输入：

- `location`
- `user_profile`
- `visit_stage`
- `available_tasks`

输出：

- 任务标题。
- 任务说明。
- 完成条件。
- 奖励或反馈。

### 2.6 文创推荐

工具名：`recommend_products`

用途：

- 根据用户兴趣、当前文化主题和访问阶段推荐文创商品。

输入：

- `interest_profile`
- `current_topic`
- `location`
- `price_preference`
- `inventory`

输出：

- 商品列表。
- 推荐理由。
- 文化关联解释。
- 购买或收藏入口。

### 2.7 Memory 更新

工具名：`update_user_memory`

用途：

- 将可靠行为和偏好变化写入短期或长期 Memory。

输入：

- `event`
- `current_memory`
- `confidence`
- `memory_scope`

输出：

- 更新后的画像字段。
- 写入理由。
- 置信度变化。

## 3. Workflow 1：首次进入场馆

目标：快速建立访问目标，并生成第一条个性化路线。

流程：

```text
1. 接收定位事件
2. 读取用户长期 Memory
3. 判断是否有明确访问偏好
4. 如无偏好，询问 1 个轻量问题
5. 调用 recommend_spots
6. 调用 plan_route
7. 输出开场建议
8. 写入 Session Memory
```

输出示例：

```text
你现在在入口区。根据你之前更喜欢历史故事和慢节奏参观，我建议走“王朝记忆线”，大约 70 分钟。第一站可以先去青铜器展厅，我会用故事方式讲，不会太学术。
```

## 4. Workflow 2：点位停留触发讲解

目标：把停留行为转化为个性化文化内容。

触发条件：

- 用户靠近点位。
- 停留超过阈值。
- 当前没有正在播放的内容。
- 未在冷却时间内。

流程：

```text
1. Context Engine 判断 deep_viewing
2. 读取点位信息和用户兴趣
3. 调用 search_cultural_knowledge
4. 调用 generate_explanation
5. 输出个性化讲解
6. 根据用户反馈更新 Memory
```

## 5. Workflow 3：兴趣驱动路线调整

目标：用户兴趣变化后动态优化路线。

流程：

```text
1. 发现用户连续关注同一主题
2. 更新 Session Memory 的 recent_topics
3. 调用 recommend_spots 查找相关点位
4. 调用 plan_route 重新排序
5. 给用户解释调整原因
```

输出示例：

```text
我发现你对建筑纹样挺感兴趣，后面可以少走一个通史展区，改去屋脊兽展区。距离更近，也和刚才看到的纹样有关。
```

## 6. Workflow 4：互动任务触发

目标：提升参与感和沉浸感。

触发条件：

- 用户处于探索阶段。
- 当前点位有任务模板。
- 用户偏好互动或亲子同行。
- 未频繁触发任务。

流程：

```text
1. 判断用户状态是否适合互动
2. 调用 trigger_task
3. 展示任务
4. 监听完成行为
5. 完成后生成反馈
6. 更新 Memory 和任务记录
```

## 7. Workflow 5：文创推荐

目标：将文化兴趣自然连接到文创推荐。

触发条件：

- 用户对某主题表现出强兴趣。
- 用户接近文创商店或访问接近尾声。
- 用户未拒绝商业推荐。

流程：

```text
1. 提取当前兴趣主题
2. 调用 recommend_products
3. 生成文化关联解释
4. 输出低打扰推荐
5. 根据点击、收藏、购买行为更新 Memory
```

输出原则：

- 不生硬售卖。
- 解释商品与文化内容的关系。
- 提供收藏、稍后查看、导航到商店等选项。

## 8. Workflow 6：用户主动提问

目标：处理用户自由问题，并与上下文结合。

流程：

```text
1. 解析用户问题
2. 判断是否需要工具
3. 检索相关知识或路线数据
4. 结合 Context 和 Memory 生成回答
5. 推荐可选下一步
6. 必要时更新 Memory
```

## 9. 失败兜底

### 9.1 定位不准

处理：

- 向用户确认当前位置。
- 提供地图点选。
- 使用最近一次可靠位置。

### 9.2 知识检索为空

处理：

- 回答已知范围。
- 明确不确定性。
- 推荐附近相关内容。

### 9.3 路线规划失败

处理：

- 降级为点位推荐。
- 给出人工规则路线。
- 请求用户选择时间或偏好。

### 9.4 用户拒绝主动服务

处理：

- 进入冷却时间。
- 降低主动触发频率。
- 保留静默导航能力。

## 10. Workflow 评估指标

- 工具调用成功率。
- 端到端响应时延。
- 主动推荐接受率。
- 任务触发参与率。
- 路线调整采纳率。
- 文创推荐点击率。
- Memory 更新准确率。
