# 蔚县暖泉古镇场景定位草案

## 1. 场景定位

蔚县暖泉古镇适合作为项目 P0 阶段的首个示范场景。它不是单一展馆，而是由古堡、寺庙、古街巷、非遗表演、剪纸工艺、民俗消费共同构成的开放式文化体验场。

产品定位可以定义为：

> 面向暖泉古镇的情境感知数字人，围绕古堡建筑、非遗体验、夜游表演和文创消费，为游客提供主动式讲解、路线规划、互动任务和可信推荐。

## 2. 为什么适合作为 P0 场景

### 2.1 文化主题集中

暖泉镇具备历史文化名镇属性，西古堡、暖泉华严寺、暖泉当铺、打树花、蔚县剪纸等元素可以形成清晰的文化资产池。

### 2.2 空间漫游价值明显

古镇场景天然需要路线引导。用户会在入口、古堡、街巷、寺庙、演出区、文创消费点之间移动，适合验证 Context 驱动的主动服务。

### 2.3 非遗与消费服务自然衔接

打树花和蔚县剪纸既是文化内容，也是互动任务和文创推荐的入口。系统可以从“讲解文化”自然过渡到“推荐体验、商品或服务”。

### 2.4 适合沉淀用户关系

不同游客的偏好差异明显：

- 摄影用户关注古堡、街巷、夜景和打树花。
- 亲子家庭关注安全、互动任务、轻松路线。
- 文化深度用户关注古建、水陆壁画、非遗传承。
- 消费用户关注剪纸、纪念品、地方特产。

这些偏好都可以沉淀到 Memory，成为后续推荐和信任机制的基础。

## 3. P0 体验闭环

建议第一版 Demo 聚焦一条可讲清楚的闭环：

```text
用户进入暖泉古镇
  -> 系统识别用户兴趣和时间
  -> 推荐古堡/非遗/夜游路线
  -> 到达西古堡或华严寺时主动讲解
  -> 在剪纸或古建点位触发互动任务
  -> 临近夜间时提醒打树花信息
  -> 游览后推荐剪纸、打树花主题纪念品或地方特产
  -> 将兴趣偏好写入 Memory
```

## 4. 初始目标用户

### 4.1 初次到访游客

需求：

- 不知道怎么逛。
- 希望快速理解暖泉古镇的重点。
- 需要一条省心路线。

服务重点：

- 入口欢迎。
- 90 分钟核心路线。
- 必看点位解释。

### 4.2 文化深度用户

需求：

- 想了解古堡、寺庙、壁画、非遗背景。
- 不满足于简单拍照打卡。

服务重点：

- 深度讲解。
- 证据来源。
- 主题串联。

### 4.3 亲子家庭

需求：

- 路线不能太累。
- 内容要有趣、可互动。
- 需要安全和休息提醒。

服务重点：

- 轻松路线。
- 寻找纹样、识别剪纸等任务。
- 休息点和时长提醒。

### 4.4 夜游与摄影用户

需求：

- 关注打树花、夜景、拍摄点位。
- 需要时间提醒和动线规划。

服务重点：

- 表演信息提醒。
- 拍摄位置建议。
- 夜游路线。

### 4.5 文创消费用户

需求：

- 想买有文化含义的纪念品。
- 希望知道商品和古镇文化之间的关系。

服务重点：

- 剪纸、打树花、古堡纹样相关商品推荐。
- 推荐解释。
- 低打扰收藏或稍后查看。

## 5. 核心文化资产

P0 阶段建议先围绕以下资产建模：

- 西古堡：明清古建筑、全国重点文物保护单位、古堡空间叙事。
- 暖泉华严寺：全国重点文物保护单位、水陆壁画、彩绘和佛镜空间。
- 暖泉当铺：清代商业建筑、省级文物保护单位、古镇商贸记忆。
- 打树花：暖泉民俗表演、夜游体验、强视觉记忆点。
- 蔚县剪纸：国家级非遗、文创消费和互动任务入口。
- 古街巷与民居：古镇漫游、摄影、生活方式讲解。

## 6. P0 数据边界

第一版不追求覆盖全部暖泉古镇，只需覆盖：

- 8 个左右核心点位。
- 3 条游览路线。
- 5 个互动任务。
- 5 个文创/消费推荐样例。
- 4 类用户画像。

## 7. 需要人工审查的信息

以下信息需要你后续人工核对：

- 打树花当前表演时间、票价和预约方式。
- 景区实时开放时间。
- 西古堡、华严寺、当铺等点位是否均对游客开放。
- 文创店、剪纸体验店、餐饮点的真实名称和营业情况。
- 点位间步行距离和最佳路线。

## 8. 已参考资料

- 暖泉镇为中国历史文化名镇，民俗包括打树花；西古堡村、北官堡村为中国传统村落。
- 西古堡为明清古建筑，2006 年列入第六批全国重点文物保护单位。
- 暖泉华严寺为全国重点文物保护单位，资料显示其前殿保存水陆壁画，寺前有“佛镜”水池。
- 暖泉当铺位于暖泉镇煤市街，为清代古建筑，列入河北省第五批文物保护单位。
- 蔚县剪纸属于国家级非物质文化遗产代表性项目名录中的剪纸项目。
